# Eco Paper Kraft - Frontend (React)

¡Bienvenido al repositorio del Frontend de **Eco Paper Kraft**!
Este proyecto está construido con **React** y servirá como la interfaz de usuario para nuestro catálogo web y sistema de usuarios.

---

## ¿Por dónde empiezo? (Instrucciones paso a paso)

Si es tu primera vez trabajando en el proyecto o apenas estás empezando con Git y React, sigue este orden:

### 1. Preparar tu entorno de trabajo
Asegúrate de tener instalado en tu computadora:
* **Node.js** (Versión LTS recomendada)
* **Git**
* **Visual Studio Code** (o tu editor favorito)

### 2. Clonar el repositorio
Abre tu terminal en el directorio que prefieras y ejecuta:
```bash
git clone https://github.com/plasticdev06/epk-frontend.git
cd epk-frontend
